# 配布前の次作業（2026-10-20）

## 1. 互換バージョン要件の見直し（優先）

個人の検証環境と、必須最低バージョン・対応範囲を分離する。
Forgeの最低要件とビルド基準を47.4.10へ変更し、ユーザーから問題なしの報告あり。DHは2.2.1-a／3.3.0以上の正式版＋構造検査方式へ変更。DHの起動・実画面確認はユーザーが担当する。TaCZ・Oculus・Embeddiumの要件は変更していない。

| 対象 | 現在の制限／検証版 | 次の確認 |
| --- | --- | --- |
| Minecraft / Java | 1.20.1 / 17 | 維持。別Minecraft版への移植は別作業 |
| Forge | ビルド47.4.10、必須47.4.10以上 | ビルド・メニュー起動成功、ユーザー確認OK。これより古い版への引き下げは今回対象外 |
| TaCZ | ビルド・必須1.1.8-hotfix2以上 | 1.1.8、1.1.7-hotfix2の描画API・Mixin対象の差分を先に確認 |
| Embeddium | 0.3.31+mc1.20.1完全一致で地形再利用を許可 | 旧版のMixin対象と地形再利用を確認。Oculus経路にも影響 |
| Oculus | 1.8.0完全一致、対応Embeddiumも必要 | 1.7系のAPI・パイプラインを別検証 |
| Distant Horizons | 2.2.1-a／3.3.0以上の正式版＋構造検査 | 2.2.1-a／3.3.0／3.3.2／3.3.3の起動・実画面確認待ち。詳細はDH_COMPATIBILITY.md |
| Configured | 任意、設定順Mixinはrequire=0 | 未導入・対象クラスやメソッドの異なる版で起動と設定を確認 |

### 作業順

1. ビルド依存版と実行時許可範囲を分離し、比較用JARとAPI一覧を用意。
2. TaCZのモデル、ocular、カメラ、描画Mixin対象の存在とシグネチャを比較。
3. 任意MODのMixinを適用前に判定する仕組みを検討。実行時チェックだけで起動安全性を保証しない。
4. 普段のPrism環境・ワールドを変更せず、別の検証環境で起動、ADS、倍率変更、持ち替え、リロード、ワールド再入場を検証。
5. 任意MODなし、Embeddiumのみ、Oculus併用、DH併用を分けて検証。起動可とPiP対応を別々に記録。
6. 合格した範囲のみメタデータと配布資料へ反映。未確認版の上限なし対応を保証しない。

調査時点の公式資料:

- [Forge 1.20.1](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html): Recommended 47.4.10。
- [TaCZビルド設定](https://github.com/MCModderAnchor/TACZ/blob/1.20.1/gradle.properties): Forge 47.3.19。これは本アドオンの互換保証ではない。
- [TaCZ配布一覧](https://www.curseforge.com/minecraft/mc-mods/timeless-and-classics-zero/files/all?gameVersionTypeId=1&page=1): 1.1.8-hotfix2はReleaseとして配布。hotfixという名前だけで不安定版とは判定しない。
