# 傷・汚れの設定（2026-10-23）

Javaの設定参照、描画時のuniform設定、`scope_image.fsh`の分岐を確認した。現在登録されている9項目はすべて使用中。数式方式も画像方式OFF時の現役の描画経路なので削除しない。今回は表示名・説明・設定ファイルのコメントのみ整理し、保存キー・範囲・初期値・描画式・表示順は維持した。保存済みの調整値を移行・初期化する必要はない。

表示順は方式→画像選択→共通パターン→汚れ→傷→数式専用の本数。画像方式で傷が薄い場合、本数を増やしても変化しない。

| 保存キー | 役割・適用条件 | 初期値 |
| --- | --- | --- |
| surfaceTexture | ONで画像方式、OFFで数式方式。効果全体のスイッチではない | true |
| surfaceTextureType | 画像方式専用。傷と汚れの共通画像を選択（0～3） | 2：拭き跡 |
| surfacePattern | 両方式共通。画像の向き・位置／数式模様の配置を変更 | 6 |
| lensDirt | 両方式の汚れON/OFF | true |
| dirtStrength | 両方式の汚れの暗さ。傷には影響しない | 0.12 |
| lensScratches | 両方式の傷ON/OFF | true |
| scratchStrength | 両方式の傷の濃さ。本数・配置は変えない | 0.6 |
| scratchSize | 傷画像の倍率／数式の線の長さ・幅。汚れには影響しない | 1.4 |
| scratchDensity | 数式方式専用の本数倍率。画像方式では0でも影響なし | 4.0 |

「画像の種類」と「パターン番号」は別の機能。画像方式の傷・汚れは同じ画像から描画しており、別々の傷専用・汚れ専用素材を選ぶ設定ではない。

日本語・英語の表示とtooltipを更新。画像方式／数式方式を切り替えても、既存の各値はそのまま保持される。実画面での見た目とConfiguredのレイアウト確認はユーザー担当。
