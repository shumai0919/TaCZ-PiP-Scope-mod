# 表面の比較表示（一時検証）

設定「表面の比較表示（一時検証）」で切り替えます。「光学効果」はオンにしてください。通常設定・画像は変更していません。検証後は0へ戻します。

| 値 | 表示 | 確認対象 |
| --- | --- | --- |
| 0 | 従来の通常表示（既定） | 元へ戻す |
| 1 | 原画像を黒背景のまま、倍率1・回転なしでレンズに表示 | 画像自体に模様があるか |
| 2 | 現在の傷の倍率・パターンで画像表示 | 拡大・切り取りで周辺の擦れが外へ出ていないか |
| 3 | 2の画像をそのまま白い擦れとして景色に重ねる | 抑制なしの基準（画像の黒は何も加えない） |
| 4 | 3に通常の密度判定・5倍ゲイン・UV端保護・サイズ0無効を追加 | 主に密度の明度しきい値 |
| 5 | 4に照準中央・レンズ中央の保護を追加 | 中央保護 |
| 6 | 5に傷の強さを追加 | 強さ設定、傷のオンオフ |
| 7 | 6に景色の明るさによる減衰と0.9係数を追加 | 明るさ減衰 |

1～7は周辺減光・ゆがみ・汚れ・反射等を迂回して比較条件をそろえます。照準線・実際の開口形状・遮蔽は残します。したがって7と通常表示は、他の効果による景色の差まで含めて完全一致するものではありません。1～5は傷の強さ・オンオフを意図的に無視します。

同じ場所・同じスコープで3→4→5→6→7を比較し、急に見えなくなる段階を確認してください。1と2の比較では、現在の傷の大きさ1.4が画像周辺を切り取る影響も確認できます。

## コード・画像からの調査結果

密度0.5では明度しきい値が0.105625となり、その明度以下の画素がゼロになります。さらに密度の0.5倍、中央保護、明るさ減衰が乗算されます。現在の画像の中央68%四方を3画素おきにサンプルすると平均R値は約0.03、しきい値以下は約98%でした（黒い背景画素も含む割合であり、傷の98%が消えるという意味ではありません）。薄い擦れを密度しきい値が消している可能性が高いものの、実ゲームの比較は未確認です。

この検証ではまだ通常表示の抑制式を変更しません。
