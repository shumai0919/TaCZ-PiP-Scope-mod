# 表面表現の通常使用向け整理

- テクスチャ4種類は変更なし。種類・パターン・強さ・大きさの保存値も変更なし。
- 画像モードの明度しきい値と密度による減衰を削除。薄い擦れを連続的に残し、「傷の強さ」で濃さを調整。
- 中央保護、UV端保護、景色の明るさによる減衰、実際の開口・遮蔽は維持。
- 「傷の密度」を「数式模様の傷の密度」に改名。画像モードでは無視し、数式モードでは本数の制御と0で無効を維持。保存キーは同じ。
- 一時的な比較表示の設定・描画分岐・Uniformを撤去。古い設定に比較値が残っていても参照しない。Forgeの設定補正で不要キーが削除される可能性あり。

画像モードで密度を最大にする必要はなくなりました。以前より薄い擦れが見えるため、同じ傷の強さでも見た目が濃くなる場合があります。好みの強さで調整してください。新しい既定値の確定は行っていません。

確認: 画像モードで密度0/4が同じ見た目になること、強さ0で傷が消えること、数式モードでは密度が機能すること、4種類の切り替え、シェーダーON/OFF、円形/四角形、リロード時の表示。実ゲーム確認は未実施。
