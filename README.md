# TaCZ PiP Scope

TaCZ向けPicture-in-Pictureスコープアドオン（Forge 1.20.1）。通常の画面と別に拡大映像を描画し、スコープの開口内に合成します。

## 導入

検証環境はMinecraft 1.20.1、Forge 47.4.20、Java 17、TaCZ 1.1.8-hotfix2です。Minecraftを終了し、本MODのJARをmodsに配置してください。同じMODの旧JARとの重複は避けてください。ガンパック固有の依存MODは別途必要です。

設定画面にはConfiguredを使用できます（任意）。設定ファイルは `config/tacz_pip_scope-client.toml` です。設定の変更前にはバックアップしてください。

## 機能と初期設定

- スコープ形状に沿った開口・視線のずれによる遮蔽と縁のぼかし。
- ゆがみ、外周屈折、色収差、周辺減光、周辺ぼけ。
- コーティング、反射、かすみ、ゴースト、非ADSガラス表現。
- 銃のぼけ、汚れ・傷、4種類の表面テクスチャ。各効果は個別に無効化可能。
- PiPの解像度、更新上限、エンティティ・ブロックエンティティ・パーティクルの描画設定。

初期値は解像度75%、最大30FPS、拭き跡テクスチャ、パターン6、傷の強さ0.6、大きさ1.4です。画像モードの濃さは傷の強さで調整し、密度は数式モード専用です。既存の保存設定は初期値更新で上書きされません。

PiP表示は `enableLensComposite`、背景ズーム抑止は `enableWorldFovPrototype` で切り替えます。

## 互換性と制約

Embeddium 0.3.31、Oculus 1.8.0、Distant Horizons 2.2.1-a向けの共存処理があります。これらは必須依存ではありません。全シェーダー・全パックでの動作を保証するものではありません。FabulousとAcceleratedRenderingは非対応です。

EOS「ヘレナの釘」のような発光HUDのみの照準構造は、黒画面を防ぐためTaCZ標準の表示・ズームへ戻します。ユーザーによる当該銃と通常スコープの確認は成功していますが、全銃の保証ではありません。

PiPには追加のワールド描画負荷があります。反射・ゴースト・銃のぼけは近似表現で、物理光学シミュレーションではありません。

## ビルドと検証

Java 17で `./gradlew build`。成果物は `build/libs/tacz-pip-scope-0.1.0-dev.jar` です。現在のバージョンは開発版 `0.1.0-dev` のままです。

[導入後の検証](TESTING.md)／[資料一覧](docs/INDEX.md)。Gradle buildだけではtoolsの手動テストや実ゲーム表示を検証しません。通常動作の成功・描画開始ログは出さず、警告とエラーを残します。
