# TaCZ Enhanced PiP Scopes

TaCZ向けPicture-in-Pictureスコープアドオン（Forge 1.20.1）。通常の画面と別に拡大映像を描画し、スコープの開口内に合成します。作者：shumoi。バージョン：0.1.0。

## 導入

必要環境はMinecraft 1.20.1、Forge 47.4.10以上、Java 17、TaCZ 1.1.8-hotfix2以上です。Forge 47.4.10をビルド基準にし、同版＋TaCZ 1.1.8-hotfix2の最小構成で開発クライアントの起動検証に成功しています。47.4.10はユーザーからも問題なしの報告を受けています（全構成の保証ではありません）。従来の実画面確認環境はForge 47.4.20です。Minecraftを終了し、本MODのJARをmodsに配置してください。同じMODの旧JARとの重複は避けてください。ガンパック固有の依存MODは別途必要です。

設定画面にはConfiguredを使用できます（任意）。設定ファイルは `config/tacz_pip_scope-client.toml` です。設定の変更前にはバックアップしてください。

## 機能と初期設定

- スコープ形状に沿った開口・視線のずれによる遮蔽と縁のぼかし。
- ゆがみ、外周屈折、色収差、周辺減光、周辺ぼけ。
- コーティング、反射、かすみ、ゴースト、非ADSガラス表現。
- 銃のぼけ、汚れ・傷、4種類の表面テクスチャ。各効果は個別に無効化可能。
- PiPの解像度、更新上限、エンティティ・ブロックエンティティ・パーティクルの描画設定。

初期値は解像度75%、最大30FPS、拭き跡テクスチャ、パターン6、傷の濃さ0.6、大きさ1.4です。「傷の本数」は数式方式専用で、画像方式では効果がありません。「傷・汚れに画像を使用」をオフにすると数式方式へ切り替わります。既存の保存設定は変更しません。[各設定の適用条件と初期値](docs/SURFACE_SETTINGS.md)を参照してください。

PiP表示は `enableLensComposite`、背景ズーム抑止は `enableWorldFovPrototype` で切り替えます。

## 互換性と制約

Embeddium 0.3.31、Oculus 1.8.0向けの共存処理があります。Distant Horizonsは2.2.1-aと3.3.0以上の正式版を対象に、内部構造が一致するとき互換処理を有効にします。3.3.0／3.3.2／3.3.3の静的検査は成功していますが、新しい互換処理の実画面検証は継続中です。3.3系・シェーダーOFFでは、DH側のアンチエイリアスがONならPiP専用TAAを自動的に使用します。履歴は通常画面から分離しており、比較用設定は削除しました。[DH検証手順と制約](docs/DH_COMPATIBILITY.md)を参照してください。これらのMODは必須依存ではありません。将来版や全シェーダー・全パックでの動作を保証するものではありません。FabulousとAcceleratedRenderingは非対応です。

EOS「ヘレナの釘」のような発光HUDのみの照準構造は、黒画面を防ぐためTaCZ標準の表示・ズームへ戻します。ユーザーによる当該銃と通常スコープの確認は成功していますが、全銃の保証ではありません。

PiPには追加のワールド描画負荷があります。反射・ゴースト・銃のぼけは近似表現で、物理光学シミュレーションではありません。

## ビルドと検証

Java 17で `./gradlew build`。リリース用成果物は `build/libs/tacz-enhanced-pip-scopes-0.1.0.jar` です。内部MOD IDは `tacz_pip_scope` のままなので既存設定を引き継げます。更新時は旧名のJARを外し、重複導入しないでください。リリース表記への変更は未検証の互換構成の動作保証や公開完了を意味しません。

[導入後の検証](TESTING.md)／[資料一覧](docs/INDEX.md)。Gradle buildだけではtoolsの手動テストや実ゲーム表示を検証しません。通常動作の成功・描画開始ログは出さず、警告とエラーを残します。
